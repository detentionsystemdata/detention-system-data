# Security policy

## Reporting a vulnerability

Please report security issues **privately** — do not open a public issue:

- **GitHub private vulnerability reporting** (preferred): use "Report a vulnerability"
  under this repository's Security tab.
- Or email **detentionsystemdata@gmail.com** with "SECURITY" in the subject.

This is a small, volunteer-run public-good dataset. There is **no bounty program and no
guaranteed response time** — reports are welcome and reviewed as capacity allows.

## Scope

- The ingestion/build pipeline in this repository (scripts/, lib/).
- The integrity of published releases (releases/) — tampering, spoofed sources,
  hash mismatches.

**Data corrections are not security issues** — if a facility fact is wrong, open a
regular issue citing a public source, or email the address above.

## What we protect

This project holds **no personal data** — no accounts, no analytics, no user submissions.
